Mission Objective

Dengan mengerjakan mission dalam topik ReactJS ini, diharapkan student bisa mengintegrasikan data static dengan penggunaan API untuk membangun aplikasi React yang dinamis dan interaktif serta dapat mendalami framework react dengan baik.

Skill set  yang diperoleh
-	Mampu mengimplementasikan custom hooks pada React dengan baik.
-	Dapat mengimplementasikan Fetching(Axios) untuk consume API dan State management pada React seperti Redux USeContext Zustand
-	Mampu mengaplikasikan beberapa library yang digunakan pada React
Case Brief
Selamat. Ya! Kamu Junior Developer yang telah berhasil melakukan slicing dan membuat beberapa component untuk membuat aplikasi sederhana yang bisa melakukan Add, Edit, Update, dan Delete data dengan menggunakan Array di misi sebelumnya.
Selanjutnya, di misi ini kamu diminta untuk mengintegrasikan data di misi sebelumnya yang masih static menggunakan array untuk diintegrasikan dengan sebuah API.

Mission Instruction
Dalam mengerjakan project ini, kamu perlu mengikuti beberapa step yang akan memudahkan kamu dalam mengimplementasikan ReactJS dengan baik.
Step 1 : Siapkan Fake API atau Mock Data
-	Buat fake API menggunakan Mock API https://mockapi.io/ atau https://firebase.google.com/  untuk pengujian dan pengembangan.
-	Buat fungsi untuk operasi GET, UPDATE, ADD, dan DELETE data.
Step 2: Mengimplementasikan API Call
-	Instal library Axios https://axios-http.com/docs/intro atau gunakan Fetch API bawaan Javascript.
-	Buat folder khusus “services/api” untuk mengelompokkan kode pemanggilan API.
-	Kembangkan fungsi JavaScript untuk masing masing operasi GET, UPDATE, ADD, dan DELETE.
-	Gunakan URL API: Simpan URL API dasar dalam file .env untuk menghindari hardcoding.
Catatan :
-	Bisa mengimplementasikan interceptor:  Interceptor dapat digunakan untuk menagani header, logging, dan otorisasi secara terpusat.
-	Simpan Basic URL pada file .env: Menyimpan URL API di file .env membantu menjaga keamanan dan meningkatkan portabilitas kode.
-	Atau bisa menggunakan custom hooks: Custom hooks dapat membantu memisahkan logika API dari komponen React.

Poin Penilaian
Berikut ini komponen penilaian yang harus tersedia dalam aplikasi:
-	Mengimplementasikan API yang dinamis dalam melakukan GET, ADD, UPDATE, dan DELETE data dalam ReactJS.
